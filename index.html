Activity settings

Use a slow pace. The default is 17:04/km (27:28/mile), which is a 12-hour marathon, with a matching walking cadence of 105 steps per minute. That pace won't set records or count as a hard effort. Change it above if you want something else.

Off by default. Synthetic heart rate counts toward Garmin Training Load, recovery time and VO2 max.

Split into segments

Choose how many parts you want. The split points start evenly spaced; move them with the sliders, or drag the numbered lines on the elevation profile above.

Using the file

  1. In Garmin Connect on the web, go to Activities and click Import. Click Browse, choose the .fit file, then click Import Data.
  2. Check it shows as a Run. Make it private, or pause Strava sync first, if you don't want it shared.
  3. If you turned heart rate on, it counts toward Training Load and recovery. Delete the activity once you've used it.
